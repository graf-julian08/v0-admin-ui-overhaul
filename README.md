# v0 Admin UI Overhaul

## Übersicht
Das Repository **v0-admin-ui-overhaul** beinhaltet eine überarbeitete Version der Admin-Benutzeroberfläche auf Basis von Next.js, TailwindCSS und modernen UI-Komponenten.

## Projektstruktur & Architektur
- `app/`: Next.js App-Router Seitenstrukturen und Layouts.
- `components/`: Wiederverwendbare Dashboard-Komponenten und Widgets.
- `hooks/`: Benutzerdefinierte Hooks für UI-Zustände.
- `lib/`: Hilfsskripte und Utility-Funktionen.
- `styles/`: CSS-Stildateien.

## Hauptfunktionalitäten
- **Überarbeitete Benutzeroberfläche**: Modernisiertes Layout mit TailwindCSS.
- **Komponenten-Bibliothek**: Skalierbare Widgets für Admin-Dashboards.
- **Optimierte Performance**: Nutzung des Next.js App-Routers.

## Ausführung & Nutzung
Start der Entwicklungsumgebung nach Installation der Abhängigkeiten über `pnpm dev` oder `npm run dev`.
